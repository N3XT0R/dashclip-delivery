# Editorial Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended)
> or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`)
> syntax for tracking.

**Goal:** Deliver an editorial blog whose articles are maintained in the administration panel and
rendered by the existing public frontend in German and English.

**Architecture:** Language-neutral facts live on `blog_posts`, everything a reader sees lives on
`blog_post_translations` with its own slug, status and `published_at`. A route group gives the blog
its own language prefix while every other public address keeps its cookie-driven language. Data
access is concentrated in `PostRepository`, application actions in `App\Application\Blog`.

**Tech Stack:** PHP 8.4.21, Laravel 13.26.1, Blade, Tailwind 4.3.0, Vite 6.4.3, Filament 5.7.6 and
Shield 4.3.1 for the editorial panel only. MariaDB 10.11.18 in production, SQLite in memory in tests.

**Spec:** `docs/superpowers/specs/2026-09-13-blog-design.md`

**Ticket:** #327

## Global Constraints

- Run every project command in the container:
  `docker exec dashclip-delivery-sharing-1 php artisan test --parallel`.
- The administration panel is the editorial surface only. No panel component, layout, CSS or
  JavaScript may appear on a public blog page, and public routing may not couple to the panel.
- The data flow is `admin panel -> model and database -> public frontend`, never the reverse.
- Reuse the existing public building blocks: `x-public.button`, `x-public.section-heading`,
  `x-public.metadata`, and the tokens `bg-panel`, `text-muted`, `border-border`, `bg-ink`.
- The homepage and the overview render the same card component. No second card is created.
- German blog addresses carry no prefix, English ones carry `/en`. No existing public address
  changes and no redirect is introduced.
- Search uses `LIKE` predicates behind `PostRepository`. Do not add a `FULLTEXT` index: the suite
  runs on SQLite while production runs MariaDB, so that path would sit outside test coverage.
- Out of scope: the newsletter subscription and the social profile links in the footer.
- Apply ADRs 0001 to 0007. Behavioral PHPUnit tests, never PHPUnit mocks or stubs. Class suffixes
  per ADR 0002, a `BlogException` hierarchy per ADR 0004, method-level PHPDoc per ADR 0005.
- Conventional Commits per ADR 0007, every commit references #327, and every commit is pushed on
  `feature/327-blog` immediately.
- Changelog entries per ADR 0006 in the order Added, Changed, Deprecated, Removed, Fixed, Security,
  wrapped at 120 characters, without internal framework names.
- No em dashes anywhere, in code, comments, documents or commit messages.
- No new composer or npm dependencies.

```php
<?php

declare(strict_types=1);

namespace App\Services\Blog;

final class ReadingTimeService
{
    private const WORDS_PER_MINUTE = 200;

    /**
     * Derive the displayed reading time, never returning less than one minute.
     * Split on whitespace rather than using str_word_count, which treats German
     * umlauts as word boundaries and overcounts by roughly a third.
     * @param string $content
     * @return int
     */
    public function minutesFor(string $content): int
    {
        $text = trim(preg_replace('/\s+/u', ' ', strip_tags($content)) ?? '');
        $words = $text === '' ? 0 : count(explode(' ', $text));

        return max(1, (int)ceil($words / self::WORDS_PER_MINUTE));
    }
}
```

```php
declare(strict_types=1);

namespace App\Models;

use App\Enum\Blog\PostStatusEnum;
use App\Services\Blog\ReadingTimeService;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class PostTranslation extends Model
{
    use HasFactory;

    protected $table = 'blog_post_translations';

    protected $fillable = [
        'post_id', 'locale', 'slug', 'title', 'excerpt', 'content',
        'meta_title', 'meta_description', 'canonical_url', 'is_indexable',
        'status', 'published_at',
    ];

    protected $casts = [
        'status' => PostStatusEnum::class,
        'published_at' => 'datetime',
        'is_indexable' => 'boolean',
    ];

    protected static function booted(): void
    {
        static::saving(static function (self $translation): void {
            $translation->reading_minutes = app(ReadingTimeService::class)
                ->minutesFor((string)$translation->content);
        });
    }

    public function post(): BelongsTo
    {
        return $this->belongsTo(Post::class, 'post_id');
    }

    /**
     * Restrict the query to translations a reader may see right now.
     * @param Builder $query
     * @return Builder
     */
    public function scopePublished(Builder $query): Builder
    {
        return $query->where('status', PostStatusEnum::PUBLISHED)
            ->whereNotNull('published_at')
            ->where('published_at', '<=', now());
    }
}
```

Create `app/Repository/PostRepository.php`:

```php
<?php

declare(strict_types=1);

namespace App\Repository;

use App\Models\PostTranslation;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\DB;

class PostRepository
{
    private const EAGER = ['post.author', 'post.category.translations', 'post.tags.translations'];

    /**
     * Query the translations a reader may see in one language, newest first.
     * @param string $locale
     * @return Builder
     */
    public function publishedForLocale(string $locale): Builder
    {
        return PostTranslation::query()
            ->published()
            ->where('locale', $locale)
            ->with(self::EAGER)
            ->orderByDesc('published_at');
    }

    /**
     * Resolve one published article by its locale-scoped slug.
     * @param string $locale
     * @param string $slug
     * @return PostTranslation|null
     */
    public function findPublishedBySlug(string $locale, string $slug): ?PostTranslation
    {
        return $this->publishedForLocale($locale)->where('slug', $slug)->first();
    }

    /**
     * Search title, excerpt and content, ranking title matches first.
     * LIKE is deliberate: the suite runs on SQLite while production runs MariaDB,
     * so a driver-dependent fulltext path would sit outside test coverage.
     * @param string $locale
     * @param string $term
     * @return Builder
     */
    public function search(string $locale, string $term): Builder
    {
        $pattern = '%'.addcslashes($term, '%_\\').'%';

        return $this->publishedForLocale($locale)
            ->where(static function (Builder $query) use ($pattern): void {
                $query->where('title', 'like', $pattern)
                    ->orWhere('excerpt', 'like', $pattern)
                    ->orWhere('content', 'like', $pattern);
            })
            ->reorder()
            ->orderByRaw('CASE WHEN title LIKE ? THEN 0 ELSE 1 END', [$pattern])
            ->orderByDesc('published_at');
    }

    /**
     * Count the published articles per category for the sidebar.
     * @param string $locale
     * @return Collection
     */
    public function categoryCounts(string $locale): Collection
    {
        return $this->publishedForLocale($locale)
            ->join('blog_posts', 'blog_posts.id', '=', 'blog_post_translations.post_id')
            ->select('blog_posts.category_id', DB::raw('COUNT(*) as total'))
            ->groupBy('blog_posts.category_id')
            ->reorder()
            ->pluck('total', 'category_id');
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use App\Services\LocaleDiscoveryService;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class SetBlogLocale
{
    public function __construct(private readonly LocaleDiscoveryService $locales)
    {
    }

    /**
     * Force the locale carried by the route prefix, overriding the stored cookie.
     * @param Request $request
     * @param Closure(Request): Response $next
     * @param string $locale
     * @return Response
     */
    public function handle(Request $request, Closure $next, string $locale): Response
    {
        abort_unless(in_array($locale, $this->locales->list(), true), 404);

        app()->setLocale($locale);

        $response = $next($request);
        $response->headers->set('Content-Language', $locale);

        return $response;
    }
}
```
